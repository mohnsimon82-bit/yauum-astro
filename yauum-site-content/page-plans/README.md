# YAUUM 页面规划工作区

这个目录是网站后续改版的唯一页面规划依据。正式页面不再先插图、后补内容，而是按照以下顺序处理：

1. 明确页面的搜索意图和采购意图。
2. 为页面分配唯一的主关键词，避免页面之间互相竞争。
3. 确定 H1、H2、H3 层级和每个板块需要回答的问题。
4. 确定内部链接和询盘入口。
5. 确定每个板块需要的图片类型、用途和说明文字。
6. 修改 Astro 页面。
7. 分别检查电脑端和手机端。
8. 用户确认后再进入下一个页面。

## 内容来源等级

### A：可以直接使用

- 用户提供的原始页面文案
- 用户提供的真实工厂图片中可以直接观察到的内容
- 通用的服装产品、面料、工艺和采购流程知识
- 不带具体承诺的服务说明

### B：需要改写后使用

- 产品知识库中的关键词、产品分类、常见面料和工艺说明
- 行业常见流程、质量检查项目和包装项目
- 不能暗示 YAUUM 已具备、已认证或保证完成的行业知识

### C：确认前禁止发布

- MOQ、价格和样品费用
- 样品和大货交期
- 月产能、工人数量和厂房面积
- 缺陷率、检测结果和性能数值
- 洗涤次数、色牢度和缩水率保证
- 客户名称、出口市场和销售数据
- 认证、验厂和合规资质
- 响应时间、退款、赔偿和保密承诺

这些信息必须先填写到 `company-info/company-profile.md`，并由用户确认后才能成为网站事实。

## 每页规划文件必须包含

- 页面目标
- 目标客户和搜索意图
- 主关键词和辅助关键词
- SEO title 和 meta description
- H1
- 板块顺序与每个板块的任务
- 每个板块的图片要求
- 内部链接
- 主 CTA 与辅助 CTA
- 手机端注意事项
- 待用户确认的事实
