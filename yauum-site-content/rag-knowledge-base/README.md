## 检索策略

### 意图分类
- **技术可行性**: MOQ、材料、工艺能力
- **价格咨询**: 报价、样品费、大货价
- **渠道查询**: 购买流程、交期、运输
- **定制需求**: 印刷、颜色、尺寸、 logo
- **质量验证**: 参观工厂、视频验厂

### 核心检索词
- manufacturer, supplier, factory, OEM, ODM
- custom, blank, wholesale, bulk
- MOQ, sample, production time, lead time
- payment terms, shipping, FOB, CIF
